## 一、数据与安全

### Q1 我们的业务数据存在哪？会出我们的域吗？

**结论：部署形态决定数据边界，专有云形态数据不出域。**
- 专有云（Apsara Stack）：平台与数据都部署在您机房，模型推理走 PAI-EAS 本地服务，向量检索用私有检索，数据不出域。
- 公共云：数据存您云账号下的资源，按云上标准加密与隔离策略管理。
- 当前演示环境：所有业务数据是本地 JSON 种子文件（页面标 MOCK 徽标），不含任何真实客户数据。

### Q2 哪些内容会发给大模型？

**结论：只有五类动作触发模型调用，发送内容最小化。**

| 动作 | 发送内容 | 页面标识 |
|------|---------|---------|
| 反馈 AI 归因 | 该条反馈原文 | LIVE |
| 发布 AI 摘要 | 本次配置 diff | LIVE |
| 试聊 Playground | 当前对话内容 | LIVE |
| 发布 AI 评测 | 待审 Release 的配置快照 + 评测用例（含参考回复）回放 | LIVE |
| 连通性探针 | 一条固定短消息 | LIVE |

模型凭据通过环境变量注入（`apps/web/.env`，已被 .gitignore 覆盖），不进代码库、不进 git、不落审计日志。专有云形态下推理本身也在您域内完成。

### Q3 效果报告的数字是怎么算出来的？

**结论：上线后 7 天窗口内同 Agent 反馈的自动聚合，不是人工填数。**
统计口径：窗口内反馈总量、负向数与占比、严重度分布（CRITICAL/MAJOR）、归因分区分布。懒计算幂等写回，不占运行时。演示环境中的报表数值是种子示例（页面已标注「非实测」）——真实环境每个版本行的数字由真实反馈算出。

### Q4 演示环境里哪些是真的、哪些是 mock？

**结论：主动分层，不回避。**
- MOCK：业务数据（Agent/反馈/发布记录），页面全部有徽标；
- LIVE：AI 归因、发布摘要、试聊、连通性探针、发布 AI 评测，五类都是真实大模型调用；
- 真实：工程纪律——260 个测试、26 个 Zod schema 全量校验、append-only 审计日志。

## 二、部署与私有化

### Q5 支持私有化部署吗？

**结论：支持，且这是专为企业客户设计的形态之一。**
专有云形态基于 Apsara Stack：模型服务（PAI-EAS 推理）与私有向量检索都在您域内，改进闭环（反馈 → 归因 → 审批 → 版本 → 效果报告 → 回滚）与公共云完全同一套，不改代码。

### Q6 换模型的成本有多大？

**结论：改三个环境变量，不改代码。**
模型层是网关配置不是代码依赖——换模型只改 Base URL、模型 ID、API Key。演示环境已真实接入小米 MiMo（`mimo-v2.5-pro`，与阿里云完全异构的厂商）验证可插拔性：换回百炼/Qwen 同样只换配置。您已有的模型投资不浪费。

## 三、与阿里云产品的关系

### Q7 agent-up 和百炼是什么关系？会不会重复投资？

**结论：互补不重叠，百炼管「调用」，agent-up 管「改进运营」。**
百炼/Model Studio 提供模型能力与 RAG 知识库（L1）；agent-up 在其上管理 Agent 的配置、评估、发布、回滚生命周期（L2）。您在百炼上的模型与知识库投资原样复用，agent-up 让这笔消费「持续且可解释」——改进有审批、效果有报告。

### Q8 和 LangSmith / Langfuse 这类观测产品什么关系？

**结论：层次不同，它们重观测，agent-up 重改进动作的治理。**
它们强在 trace 回放与调用级观测；agent-up 强在审批、不可变版本、回滚、效果归因这些「改进动作」的治理。trace 回流在 roadmap 里，届时两层打通而非互相替代。

## 四、商务与合作

### Q9 现在能直接上生产吗？

**结论：诚实说——当前是演示形态，生产化路径明确。**
当前运行时是 JSON 文件存储 + MOCK 登录，适合演示与 POC，不适合直接生产。生产化三步：① Prisma 持久化（schema 已就绪）；② 真实认证（NextAuth 接入位已留）；③ CI 流水线。每步都有明确工作量评估，欢迎会后细聊。

### Q10 合作形态与报价怎么走？

**结论：建议 POC 起步，正式报价随商务体系，本材料不承诺价格。**
POC 建议范围：1 个产品组 + 1 个 Agent + 4 周，跑通一条完整改进闭环（真实反馈进、版本发布出、效果报告可读）。验证价值后再按部署形态谈正式合作——公共云 SaaS 订阅制或专有云项目制，报价随阿里云商务政策另行出具。
