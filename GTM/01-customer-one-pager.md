## 一句话定位

**模型是引擎，agent-up 是把引擎变成「持续改进的生产系统」的那层。**
MaaS 提供模型能力；agent-up 管 Agent 的**配置 · 评估 · 发布 · 回滚**全生命周期。

## 客户正在面对的三个痛点

| # | 痛点 | 现状的典型样子 |
|---|------|---------------|
| 1 | **改不动** | Prompt 写在代码里，改一句话要发版；业务同学提的改进意见落不了地 |
| 2 | **不敢改** | 改完不知道会不会更差；没有审批、没有快照、出事只能靠记忆回滚 |
| 3 | **说不清** | 上线后效果靠感觉；「这次改进值不值」拿不出数据，预算和模型选型都没法对齐 |

## agent-up 的解法：一条看得见、管得住、算得清的改进闭环

**反馈 → AI 归因 → 改配置 → 审批发布 → 效果报告 →（不行就）一键回滚**

- **看得见**：每条用户反馈进来，LLM 自动归因到四个配置分区之一（真实模型调用，非 PPT 概念）
- **管得住**：配置变更走 Release 审批，AI 自动生成变更摘要与风险提示；通过即生成不可变版本快照
- **算得清**：版本上线 7 天自动出效果报告（反馈量/负向比/严重度分布）；试聊 Playground 改完立即可验
- **退得出**：分区级或整版本一键回滚，回滚本身写审计日志

## 核心能力一览

| 能力 | 说明 |
|------|------|
| 四分区配置 | Prompt / Knowledge / Tools / Routing 独立编辑、独立回滚，改知识不动提示词 |
| 发布流水线 | 自动 diff 上一版本 + 真语义化版本号（patch/minor 按变更范围计算） |
| 不可变版本 | 每次发布生成完整快照，历史可追溯 |
| 效果报告 | 上线满 7 天自动聚合窗口内反馈，懒计算不占运行时 |
| AI 增强（真实 LLM） | 反馈归因 · 发布变更摘要 · Agent 试聊，均实时调用大模型 |
| 全量审计 | 所有写操作 append-only 审计，谁在何时改了什么一目了然 |

## 与「现状」的差异

| 维度 | 个人做法（prompt 存代码） | 纯模型平台（只管调用） | **agent-up** |
|------|--------------------------|------------------------|--------------|
| 改配置 | 发代码版本 | 不支持 | 页面编辑，分钟级 |
| 审批 | 无 | 无 | Release 审批 + AI 风险提示 |
| 回滚 | 靠 git revert 记忆 | 无 | 分区级/整版本一键回滚 |
| 效果度量 | 无 | 仅用量账单 | 反馈驱动的 7 天效果报告 |
| 参与角色 | 只有开发 | 只有开发 | 产品组 + CRE + 工单团队三角色协同 |

## 模型中立：公共云 + 专有云双形态

同一套改进闭环，对接两种部署形态——**模型可换，闭环不变**：

- **公共云**：百炼 Model Studio / DashScope API / Qwen 系列 / 百炼 RAG 知识库
- **专有云**：Apsara Stack 模型服务私有化 / PAI-EAS 推理 / 私有向量检索（数据不出域）

当前演示环境已真实接入小米 MiMo（`mimo-v2.5-pro`）验证 LLM 网关的可插拔性——换模型只需换配置，不需要改代码。

## 现场演示动线（5 步，约 8 分钟）

1. **`/maas`** — 点「发起真实调用」：平台连的模型是活的（显示时延与 tokens）
2. **`/feedback`** — 挑一条 NEGATIVE 反馈点「AI 归因」：LLM 指出问题在哪个分区、怎么改
3. **`/agents/ecs-assistant`** — 按归因建议改 Prompt，保存后在「试聊 Playground」立即验证
4. **`/releases`** — 提交发布 → 「查看变更」看 diff + 「AI 变更摘要」→ 点「AI 评测」看快照回放 PASSED → 审批通过生成新版本
5. **版本历史** — 展示效果报告徽标与「回滚此分区」：改坏了，一步退回去

## 诚实边界（我们主动说）

演示环境为 **mock 数据 + 真实 LLM** 混合形态：业务数据（Agent/反馈/发布）是本地种子数据，
标注 MOCK 徽标；AI 归因/摘要/试聊/发布 AI 评测是**真实大模型调用**，标注 LIVE。
生产化路线（Prisma 持久化、真实认证、CI、对接贵司数据）有明确里程碑，欢迎会后细聊。
