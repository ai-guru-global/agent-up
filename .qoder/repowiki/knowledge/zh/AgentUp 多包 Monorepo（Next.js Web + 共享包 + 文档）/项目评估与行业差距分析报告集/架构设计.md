该目录为纯文档型叶子模块，采用「README 索引 + 独立 Markdown 报告」的组织方式：`README.md` 作为报告总索引，列出所有报告的日期、类型与摘要，并维护与 `docs/superpowers/specs/`、`docs/evaluation/` 等上游设计文档的关联关系，以及与 Web 管理后台 `/architecture*` 路由的文件级对应表；每份报告以 `YYYY-MM-DD-<主题短横线英文>.md` 命名，时间戳即版本标识，同一主题的新评估新建文件而不覆盖旧文件。报告之间通过相对路径链接（如 `../superpowers/specs/...`）形成可追溯的版本链。
