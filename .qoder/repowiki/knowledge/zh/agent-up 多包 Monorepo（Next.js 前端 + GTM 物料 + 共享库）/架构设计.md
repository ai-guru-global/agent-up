根目录通过 `pnpm-workspace.yaml` 将 `apps/*` 与 `packages/*` 纳入同一工作区，并由 `turbo.json` 统一调度 `dev/build/lint/db:*` 等任务；`apps/web` 是唯一的运行时 Next.js 应用（含 App Router 页面、API Routes 与 Prisma），`packages/{db,shared,ui}` 提供数据库 schema、领域模型与 UI 组件供 web 消费，`GTM/` 作为独立静态营销资料不参与构建管线。各子模块通过 pnpm 的 workspace protocol 引用共享包，Turbo 负责跨包依赖解析与缓存，`docker-compose.yml` 则用于本地基础设施编排。
