- 领域类型按资源拆分为 `src/types/<domain>.ts` 单文件，并通过 `index.ts` 统一 barrel 导出。
- 状态/分类类值一律使用字符串字面量枚举（`enum Xxx { A = "A", ... }`），而非数字枚举或联合字面量。
- 跨文件类型引用统一采用 `import type { ... }` 语法，确保零运行时开销。
- 实体接口遵循 `id: string` + 审计字段（`submittedBy/submittedAt/approvedBy/approvedAt`）+ 时间戳（`createdAt/updatedAt/publishedAt`）的统一命名约定。
