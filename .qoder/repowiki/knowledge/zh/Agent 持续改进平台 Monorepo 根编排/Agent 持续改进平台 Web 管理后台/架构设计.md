本模块是 Turborepo 下的独立 Next.js 16 应用，采用 App Router + 路由组划分边界：`(auth)` 存放登录页，`(dashboard)` 承载所有管理后台页面并通过 `layout.tsx` 渲染侧边栏导航；`app/api/` 下按资源域（agents、feedback、releases、settings、skills、wiki）组织 RESTful Route Handlers，每个 `route.ts` 仅做参数解析与校验，再委派给 `lib/services/*` 中的领域服务函数。

- 数据层：通过 pnpm workspace 依赖 `@agent-up/db` 与 `@agent-up/shared`，Prisma schema 位于 `prisma/schema.prisma`，数据库连接由共享包提供，本应用不直接持有 Prisma Client 实例。
- 校验层：`lib/schemas.ts` 集中定义 Zod schema 并导出对应 TypeScript 类型，API route 统一使用 `safeParse` 返回结构化错误。
- 响应层：`lib/utils.ts` 暴露 `success` / `error` / `parsePagination` / `paginationMeta` / `parseBody` 等工具，所有 API 端点遵循 `{ success, data }` 或 `{ success, error, errors }` 的统一 JSON 格式。
- UI 层：`components/ui` 预留组件目录，当前仪表盘布局以 Tailwind CSS v4 内联样式实现。
- 构建与运行：`next.config.ts` 保持默认配置，开发模式启用 Turbopack（`--turbopack`），由根级 `turbo.json` 统一编排 dev/build/lint。
