本模块是一个独立的 npm 包 `@agent-up/ui`，通过 pnpm workspace 被上层应用消费。入口文件 `src/index.ts` 仅暴露一个 `version` 常量作为占位导出，注释指明后续集成 shadcn/ui。构建由根级 `tsconfig.json` 扩展而来（`extends ../../tsconfig.json`），并针对 React JSX 开启 `jsx: react-jsx`，输出目录为 `./dist`。依赖方向单向：自身声明对 `react`/`react-dom` 的 `peerDependencies`，避免重复打包；同时保留 `dependencies` 以支持本地开发时直接 `tsc` 编译。
