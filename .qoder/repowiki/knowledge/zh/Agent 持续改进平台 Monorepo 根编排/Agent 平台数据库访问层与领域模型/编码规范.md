- 对外统一从 `index.ts` 再导出，内部实现放在独立文件（如 `client.ts`）以避免循环依赖。
- 全局单例通过 `globalThis` 守卫并在非 production 环境下缓存，防止热重载重复创建连接。
- 领域模型以 `Agent` 为核心聚合根，相关配置拆分为独立 model 并通过一对一 relation 关联，复杂运行时数据使用 JSON 字段存储。
- 所有实体采用 `id String @id @default(cuid())` 主键约定，并附带 `createdAt` / `updatedAt` 审计时间戳。
- 状态类字段统一使用 enum 定义（如 `AgentStatus`、`FeedbackStatus`、`SkillStatus`），而非字符串魔法值。
