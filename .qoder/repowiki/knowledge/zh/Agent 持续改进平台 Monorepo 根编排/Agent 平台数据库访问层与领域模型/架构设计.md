本模块是 monorepo 中唯一的数据库依赖入口，仅包含两个源文件：`src/client.ts` 通过 `globalThis` 在 HMR / 多进程场景下复用同一个 `PrismaClient` 实例，避免热重载产生连接泄漏；根据 `NODE_ENV` 切换 query/error/warn 日志级别。`src/index.ts` 作为对外统一出口，同时 re-export 单例 `prisma` 和全部 `@prisma/client` 生成的类型（`export type *`），使上层包无需直接引用 `@prisma/client`。`package.json` 将 `main` 与 `types` 指向 `src/index.ts`，并通过 `db:generate` / `db:push` / `db:migrate` / `db:studio` 脚本暴露 Prisma CLI 能力，依赖方向单向向外——其他包只消费此包，不反向依赖它。`prisma/schema.prisma` 定义了 Agent 持续改进平台的完整领域模型，围绕 `Agent` 实体组织四分区配置（Prompt/Knowledge/Tools/Routing）、版本快照（`AgentVersion` + `Release`）、反馈闭环（`Feedback` + `ConfigChange`）、技能插件体系（`Skill` + `AgentSkillBinding` + `SkillVersion`）、Wiki 知识库（`WikiVault` + `WikiPage` + `WikiIngestJob`）以及 RBAC 权限与审计（`Role` / `Permission` / `UserRole` / `AuditLog`），所有复杂结构以 JSON 字段承载运行时配置，配合枚举描述状态机。
