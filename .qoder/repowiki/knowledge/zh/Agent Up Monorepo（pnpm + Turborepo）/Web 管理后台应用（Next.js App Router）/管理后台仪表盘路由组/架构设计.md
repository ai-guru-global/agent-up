采用 Next.js App Router 的路由组 `(dashboard)` 将一组受侧边栏布局保护的页面聚合在一起：
- `layout.tsx` 定义共享的 DashboardLayout，包含左侧固定宽度导航栏（通过 `navItems` 数组声明式配置）和右侧主内容区，所有子路由自动复用该布局。
- 每个功能域以独立目录组织（`agents/`、`feedback/`、`releases/`、`skills/`、`settings/`），每个目录下的 `page.tsx` 导出一个默认 React 组件作为页面入口；动态段使用 `[id]` 和 `versions/[agentId]` 命名约定。
- 当前阶段为纯 UI 骨架（占位文案 + Tailwind 样式），尚未集成数据获取或业务逻辑，依赖方向单向向下（页面 → 组件），无跨模块服务层。
