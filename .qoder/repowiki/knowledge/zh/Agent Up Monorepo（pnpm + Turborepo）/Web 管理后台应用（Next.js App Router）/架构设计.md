本模块是 Turborepo 下的一个独立 Next.js 16 应用，采用 App Router + 路由组 `(auth)`、`(dashboard)` 划分认证与管理后台边界；`app/api/agents/route.ts` 提供服务端 API 端点，`lib/prisma.ts` 与 `prisma/schema.prisma` 直连数据库，并通过 pnpm workspace 依赖 `@agent-up/shared` 与 `@agent-up/db` 两个内部包复用类型与数据访问层。根级 `package.json` 通过 `turbo run dev/build/lint` 统一编排该子应用的启动、构建与代码检查，形成以 Next.js 为运行时、Prisma 为 ORM、Turborepo 为任务编排的三层协作结构。
