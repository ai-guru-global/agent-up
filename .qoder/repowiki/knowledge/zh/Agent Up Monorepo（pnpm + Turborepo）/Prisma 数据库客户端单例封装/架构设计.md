本模块是 monorepo 中唯一的数据库依赖入口，仅包含两个源文件：`src/client.ts` 通过 `globalThis` 在 HMR / 多进程场景下复用同一个 `PrismaClient` 实例，避免热重载产生连接泄漏；根据 `NODE_ENV` 切换 query/error/warn 日志级别。`src/index.ts` 作为对外统一出口，同时 re-export 单例 `prisma` 和全部 `@prisma/client` 生成的类型（`export type *`），使上层包无需直接引用 `@prisma/client`。`package.json` 将 `main` 与 `types` 指向 `client.ts`，并通过 `db:generate` / `db:push` / `db:migrate` 脚本暴露 Prisma CLI 能力，依赖方向单向向外——其他包只消费此包，不反向依赖它。
