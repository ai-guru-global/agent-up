本模块是一个纯类型包（`private: true`），通过 `src/index.ts` 作为单一入口，使用 `export * from "./types/<domain>"` 的桶式导出聚合所有领域类型；每个领域（agent、feedback、release、skill、wiki、permission）独立一个文件，按资源边界划分，避免跨域耦合。类型之间仅通过 `import type { ConfigPartition } from "./agent"` 这种类型导入引用共享枚举，保持零运行时依赖。`package.json` 将 `main` 和 `types` 都指向 `src/index.ts`，配合 `tsc` 直接编译，供上层服务/前端以类型消费方式引入，不产生业务逻辑。
