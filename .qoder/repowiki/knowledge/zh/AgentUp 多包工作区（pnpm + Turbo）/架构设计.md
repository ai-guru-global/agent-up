根目录作为 monorepo 入口，通过 pnpm-workspace.yaml 将 apps/* 与 packages/* 纳入同一依赖图；turbo.json 定义跨包的 task 依赖链：build 先触发 ^build 与 ^db:generate，dev 强制依赖 db:generate，lint 依赖 build，所有 db:* 与 clean 任务关闭缓存以保证 SQLite 状态一致。web_app 作为运行时主应用消费 db_package 的 Prisma 客户端，chrome_extension 通过 HTTP 调用 web_app 暴露的 /api/feedback 端点完成反馈上报；docs 与 knowledge_base 为纯 Markdown 资产，由 code-up.yaml / skills-up.yaml 驱动的 AI 蒸馏与技能门禁流程消费。tsconfig.json 提供全局 TS 编译基线（ES2022、bundler 解析、strict + noEmit），Node ≥20 为运行约束。
