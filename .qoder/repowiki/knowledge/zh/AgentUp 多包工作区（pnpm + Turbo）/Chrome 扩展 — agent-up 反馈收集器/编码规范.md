- popup 与 content.js 之间通过 chrome.tabs.sendMessage / chrome.runtime.onMessage 传递 {type, payload} 结构的消息，类型常量以 AU_ 前缀命名（AU_GET_STATE、AU_SUBMIT）。
- content.js 对页面状态的读取与 API 提交统一返回 {ok, ...} 对象，错误路径通过 ok=false 与 error/reason 字段区分，popup 据此切换视图而非抛错。
- popup 内部用 $ 选择器缓存 DOM 引用到一个 els 对象，并以 hidden 属性配合 show(name) 函数在 checking/empty/ready/done 四个 view 间切换。
- 所有面向用户的文案与提示使用中文，代码注释采用 JSDoc 风格说明函数职责与边界条件。
