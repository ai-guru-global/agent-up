扩展由 manifest.json 声明三个职责面：
- content_scripts（content.js）：注入到 http://localhost:3000 与 127.0.0.1:3000 的 Agent 详情页，负责解析 URL 中的 agentId、同源拉取 /api/agents/:id 获取名称、从 DOM 中抽取 role="log" 的 Playground 对话为结构化 turn 列表，并通过 chrome.runtime.onMessage 暴露 AU_GET_STATE / AU_SUBMIT 两个消息接口。
- popup（popup.html + popup.css + popup.js）：用户交互层，使用 chrome.tabs.sendMessage 把请求委托给 content.js，自身维护 checking → ready/empty → done 视图状态机，渲染证据预览并校验标题/正文必填。
- icons/：多尺寸 PNG 图标及 SVG 源图。
依赖方向单向：popup → content_script → agent-up 后端 API；popup 不直接访问页面 DOM 或跨域调用，所有页面读取与 POST /api/feedback 均经 content.js 以同源方式执行，规避 CORS 限制。身份走 x-actor-* 请求头（MOCK 认证占位）。
