- 文档命名采用 `YYYY-MM-DD-<主题>.md` 时间戳前缀，同主题新一轮产出另建文件而不覆盖旧版本。
- 设计规格书在 `superpowers/specs/` 中以 `YYYY-MM-DD-<主题>-design.md` 命名，并在 README 中维护 Draft → Approved → Implemented/Partially Implemented 的状态表。
- Markdown 文档统一使用 YAML frontmatter 携带 `title / depth / component_score / generated / source_commit` 等元数据，供 code-up/skills-up 自动化消费。
- 引用代码一律使用相对路径加 file:line 锚点格式 `[file.ts:42-50](relative/path#L42-L50)`，禁止绝对路径。
- 推测性内容以 `> [!NOTE] 推测：...` 标注，浅度分析显式标记深度等级（core/standard/shallow）。
- GTM 物料采用 `NN-<主题短横线英文>.md` 序号命名，所有对外数字（测试数、Zod schema 数、API route 数等）集中在 `GTM/README.md` 的事实口径表中集中维护。
