- API 响应统一通过 `success(data)` 包裹，错误通过 `handleApiError(err)` 转换，避免在 handler 内直接 return JSON。
- 需要审计身份的写操作使用 `withActor(resolveActor(request.headers), () => ...)` 包裹业务函数，将当前操作人注入到下游服务。
- 请求体校验采用 `validateBody(request, <zodSchema>)`，失败时直接返回 `validated.response`，成功分支再执行业务逻辑。
- Release 相关实体查询统一使用 `toReleaseResponse(row)` 进行字段裁剪，避免把内部模型直接暴露给前端。
- 未找到资源时抛出 `NotFoundError("Release 不存在")`，由上层 `handleApiError` 统一转为 HTTP 404。
