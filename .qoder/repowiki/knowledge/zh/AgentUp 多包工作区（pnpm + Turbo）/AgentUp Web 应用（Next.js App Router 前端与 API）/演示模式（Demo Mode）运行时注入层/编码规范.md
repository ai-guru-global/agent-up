- API 路由通过 `pathname.split("/")` 取段后按 `[head, second, third, fourth]` 解构进行 if/else 分支匹配，而非使用外部路由框架。
- 错误处理统一抛出 `MockError(status, message)`，由顶层 try/catch 捕获后转为 `{ success: false, error }` 响应。
- 对外返回体统一经 `ok(data)` / `fail(error)` 包装器封装，保持与真实服务端 `success/data` 或 `success/error` 形状一致。
- 业务逻辑函数（如 `withProductGroup`、`withAgentName`、`computeEffectivenessReport`）被注释标注“镜像 xxx-service”，用于对齐服务端 service 层语义而非复制实现。
- 时间戳统一通过 `now()` 辅助函数生成 ISO 字符串，ID 通过 `newId()` 基于 `crypto.randomUUID` 或降级生成。
