模块以 `install-fetch.ts` 作为副作用入口——在浏览器环境且 `NEXT_PUBLIC_DEMO_MODE=1` 时 patch `window.fetch`，将同源 `/api/*` 请求转发给 `mock-server.ts` 的 `handleMockRequest`，其余透传真实 fetch。

- `seed.ts` 是单一事实源：从 `@agent-up/db/prisma/seed-data.mjs` 和编译产物 `wiki-corpus.mjs` 构造 `DemoState`，并通过 `createInitialState()` 深拷贝出可变的内存态；`RESERVED_AGENT_IDS` 保证静态导出下新建 Agent 有详情页。
- `mock-server.ts` 实现完整的内存态 API router，镜像服务端 route handler 的请求/响应形状（分页、join、版本 bump、证据链、版本演进线、反馈状态机、LLM 预置回复等），所有变更只落内存，刷新即重置；通过 `resetDemoState()` 暴露重置能力。
- `demo-provider.tsx` 是 React 挂载点（`"use client"`），由 root layout 在 demo 模式下渲染，先 import `install-fetch` 再渲染 `DemoBanner`。
- `demo-banner.tsx` 提供 UI 提示与一键重置按钮。
- `demo-deep-link-redirect.tsx` 解决 Meoo CDN 无扩展名深链接回落到根 index.html 的路由修复问题。

依赖方向单向：UI 组件 → `install-fetch` → `mock-server` → `seed`；纯算法（如 BM25 检索）复用 `@/lib/retrieval-bm25`，避免在服务端与演示轨之间复制逻辑。
