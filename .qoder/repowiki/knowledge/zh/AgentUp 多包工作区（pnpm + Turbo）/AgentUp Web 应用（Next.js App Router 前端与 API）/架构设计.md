以 apps/web 为单一 Next.js 应用边界：app/ 下按业务域拆分 (auth)、(dashboard) 等路由组，每个域同时提供页面（.tsx）与 /api 下的 RESTful route.ts；所有跨域能力下沉到 lib/（认证令牌、Zod schema、错误体系、BM25、版本差异等）与 components/ui/（Primitives、Modal、Form、Status）。运行时通过 instrumentation.ts 在 Node 进程启动时校验 AUTH_SECRET 并主动 process.exit，避免 edge runtime 误加载服务端依赖。演示模式由 demo/ 注入层拦截 /api 请求到内存 mock 服务，与真实路由共存。测试使用 Vitest + @vitest/coverage-v8 直接运行 route.ts 与 lib 代码，生成 coverage/app/api 与 coverage/lib 两套 HTML 报告。
