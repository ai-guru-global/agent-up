- 客户端组件以 `'use client'` 指令开头并通过 `fetch('/api/maas/*')` 直接调用同模块下的 Route Handler，不在页面层引入额外状态管理。
- API Route Handler 统一使用 `success(data)` 包装成功响应，并在 try/catch 中用 `handleApiError(err)` 返回错误，避免在 handler 内分散错误处理。
- LIVE 与 MOCK 数据在同一 UI 中并列呈现：有真实数据时显示 `Badge tone="success"` 标注 LIVE，无数据时回退到预置 MOCK_ROWS 并以 `Pill tone="neutral"` 标注 MOCK，同时附带诚实口径说明。
- 所有对外部 LLM 调用的耗时、token 消耗、模型标识等元数据均作为结构化字段返回给前端展示，而非仅返回文本结果。
