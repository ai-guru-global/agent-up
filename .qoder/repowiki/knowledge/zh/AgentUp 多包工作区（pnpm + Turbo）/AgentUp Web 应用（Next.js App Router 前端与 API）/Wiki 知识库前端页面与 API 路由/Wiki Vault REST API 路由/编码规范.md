- Handler 对写入操作（POST/PUT/DELETE）使用 `withActor(resolveActor(request.headers), () => ...)` 包裹业务调用以注入当前 Actor 上下文。
- 请求体校验统一通过 `validateBody(request, <schema>)` 并立即检查 `validated.ok` 返回 `validated.response`，失败时不再继续执行业务逻辑。
- 成功响应一律经 `success(data, status?)` 封装，错误经 `handleApiError(err)` 或显式 `error(message, code)` 返回。
- 分页查询从 URL searchParams 中用 `parsePagination` 提取 `skip/take/page/pageSize`，并以 `{ items, pagination: paginationMeta(...) }` 结构返回。
- 动态路由参数采用 Next.js 13+ 的异步 params 形式：`const { id } = await params`，而非解构函数参数。
