基于 Next.js App Router 的路由目录结构：`route.ts` 暴露 Vault 自身的 GET/POST（列表与创建），`[id]/route.ts` 暴露单条 Vault 的 GET/PUT/DELETE，`[id]/pages/route.ts` 管理该 Vault 下的 Page 子资源（分页查询 + 创建），`[id]/search/route.ts` 提供向量检索入口。

- 所有 handler 仅做请求解析、参数校验与错误包装，业务逻辑委托给 `@/lib/services/wiki-service`（Vault/Page CRUD）与 `@/lib/services/retrieval-service`（searchWiki）。
- 身份上下文通过 `withActor(resolveActor(request.headers), ...)` 注入，写操作（POST/PUT/DELETE）均包裹在 actor 上下文中执行。
- 统一响应格式由 `@/lib/utils` 的 `success`/`error` 返回；参数校验走 `zod` schema（`createWikiVaultSchema`、`updateWikiVaultSchema`、`createWikiPageSchema`、`wikiSearchQuerySchema`）。
- 依赖方向单向向外：handler → lib/utils + lib/schemas + lib/context → lib/services → 外部存储/检索服务，本模块不直接访问数据库。
