基于 Next.js App Router 的 `(dashboard)` 路由组，按主题拆分为四个并列页面：`page.tsx`（架构总览）、`loop/page.tsx`（Loop 工程）、`harness/page.tsx`（Harness 工程）、`roadmap/page.tsx`（改进路线图）。所有页面共享 `./_components/ui.tsx` 中的展示型组件（PageHeader/Section/Card/Table/Pill/Insight/NavGrid/References/ScoreDots），不引入业务状态或数据层，纯渲染层。

- 内容组织：每个页面以常量字符串形式内嵌 Mermaid 图定义（flowchart/sequenceDiagram/quadrantChart），通过 `../../../components/mermaid` 的 `<Mermaid>` 客户端组件在浏览器端渲染。
- 导航结构：总览页底部用 `NavGrid` 链接到 loop/harness/roadmap 三个深入页；各深入页末尾用 `<a href="/architecture/...">` 互相跳转，形成「总览 → 专题」的双向导航。
- 依赖方向：页面 → `_components/ui.tsx` → Next.js 内置组件；页面之间无相互 import，仅通过 URL 耦合。
- 可访问性：Table 带 sr-only caption + tabIndex 横向滚动容器；Pill/ScoreDots/References 使用 aria-label/sr-only 提升读屏体验；颜色全部走 CSS `var(--*)` 语义 token，避免硬编码对比度问题。
