- API 路由对成功响应统一使用 `success(data, status?)` 包装，错误路径统一返回 `error(message, code)` 或通过 `handleApiError(err)` 转换。
- 写操作的请求体先经 `validateBody(request, xxxSchema)` 校验，失败时直接返回 `validated.response`，成功后再进入业务逻辑。
- 需要身份上下文的写操作统一包裹在 `withActor(resolveActor(request.headers), () => ...)` 中，将当前 Actor 注入到 service 层调用。
- 前端列表页通过 URLSearchParams 拼接 `category`、`status`、`search` 查询参数，并在 `useEffect` 中随状态变化重新拉取数据。
