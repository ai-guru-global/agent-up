本模块由三个 Next.js App Router 路由文件组成，均位于 `apps/web/app/api/agents/[id]/` 下，职责清晰分层：
- `skills/route.ts`：CRUD 式技能绑定接口，GET 列出绑定、POST 绑定、DELETE 解绑，通过 `@/lib/services/skill-service` 访问持久层。
- `config/[partition]/route.ts`：统一的分区配置读写入口，用 `VALID_PARTITIONS` + `PARTITION_ENUM` 白名单校验 partition，PUT 时根据分区分派到 `updatePromptConfig/updateKnowledgeConfig/updateToolsConfig/updateRoutingConfig`，并在成功后调用 `recordConfigChange` 记录变更审计。
- `config/[partition]/rollback/route.ts`：基于 `agentVersion` 快照的一键回滚，读取对应 snapshot 列后复用分区更新函数并追加 `_ROLLBACK` 类型的变更记录。
- `chat/route.ts`：Agent 试聊 Playground，从 DB 加载 agent 的 promptConfig，经 `buildSystemPrompt` 组装 system prompt 后调用 `chatCompletion`，并将整轮上下文落盘为 trace。

依赖方向单向向外：路由层仅负责参数解析、body 校验（`validateBody`）、Actor 注入（`withActor(resolveActor(...))`）和错误包装（`handleApiError`），业务逻辑下沉至 `@/lib/services/*`，数据模型来自 `@agent-up/db`（Prisma）。
