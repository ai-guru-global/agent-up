- 路由函数统一使用 `success(data)` / `error(msg, code)` 返回标准化 JSON 响应，异常通过 `handleApiError(err)` 捕获。
- 写操作在 `withActor(resolveActor(request.headers), () => ...)` 包裹内执行，以注入当前 Actor 上下文。
- 请求体校验统一通过 `validateBody(request, schema)`，若 `validated.ok === false` 直接返回其 response。
- 分区类路由（config）使用 `VALID_PARTITIONS as const` 白名单 + `isValidPartition` 守卫 + `PARTITION_ENUM` 映射表来枚举合法分区并转为后端枚举值。
- 分区更新路径采用 switch 分派到 `updatePromptConfig/updateKnowledgeConfig/updateToolsConfig/updateRoutingConfig`，并在成功后调用 `recordConfigChange(id, type, before, after)` 记录审计日志。
