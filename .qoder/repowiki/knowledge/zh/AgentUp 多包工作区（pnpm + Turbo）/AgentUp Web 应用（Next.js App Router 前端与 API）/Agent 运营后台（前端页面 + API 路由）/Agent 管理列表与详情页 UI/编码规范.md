- 所有页面与组件使用 `'use client'` 指令并通过浏览器原生 `fetch` 直接调用 `/api/*` REST 端点，不在本模块内封装数据服务层。
- 异步请求统一采用「success/error/catch」三段式：成功时取 `json.data`，失败时清空列表并设置错误消息，catch 中置为网络错误，且 loading 在 finally 中关闭。
- 在 `useEffect` 内发起请求前同步重置 loading/error 状态，并用 eslint-disable 注释显式豁免 `react-hooks/set-state-in-effect`，避免竞态导致旧响应覆盖新状态。
- 列表/详情加载态使用 `<Skeleton>` 占位并配合 `role="status" aria-live="polite"` 与 `.sr-only` 文本提供无障碍提示。
- 空数据与加载失败分别走 `<EmptyState>` 与 `<Alert tone="danger">`，失败 Alert 通常暴露 `onRetry` 回调以便原地重试而不刷新页面。
- 表单字段统一通过 `@/components/ui` 的 `Field` 高阶组件包装，内部用 render prop 传入 `{ id, describedBy }` 并透传给 `Input`/`Textarea`/`Select` 以满足 a11y。
