基于 Next.js App Router 的 `(dashboard)` 路由组：
- `agents/page.tsx` 为 Agent 列表页，负责搜索/状态筛选、新建 Agent 弹窗（调用 `/api/agents` POST 与 `/api/settings/product-groups`）。
- `agents/[id]/page.tsx` 是动态路由壳，通过 `generateStaticParams` 预渲染种子 ID + 预留池 ID，使新建 Agent 可直接导航；默认导出仅包裹 `<AgentDetailPage />`。
- `agent-detail.tsx` 是核心容器组件，维护 agent 主数据、四分区（prompt/knowledge/tools/routing）标签页、草稿保存、版本历史与回滚，并组合子面板 `EvalCasePanel`、`EvidenceChainPanel`。
- `eval-case-panel.tsx` 与 `evidence-chain-panel.tsx` 作为独立可复用面板，分别对接 `/api/agents/${agentId}/eval-cases` 与 `/api/agents/${agentId}/evidence-chain`。
所有数据获取均通过浏览器原生 `fetch` 直接请求后端 REST API，不经过 Apollo/React Query 等数据层；UI 组件统一从 `@/components/ui` 导入（Field/Input/Select/Alert/Skeleton/EmptyState/Modal 等），类型定义在文件内以接口形式声明，依赖方向单向：页面 → 子面板 → 后端 API。
