- 数据库侧所有枚举值以 String 列存储，类型安全由 `src/enums.ts` 的同名 const 对象 + union type 提供，运行时值域校验交给调用方的 Zod schema。
- JSON 与字符串数组一律序列化为 String 列存储，读写必须经过 `src/json-text.ts` 的 `packJson`/`unpackJson`，解析失败时返回 fallback 值而非抛出异常。
- 模型主键统一使用 `cuid()` 生成的 String 类型 id，时间戳字段使用 `DateTime @default(now())` 与 `@updatedAt` 组合。
- 对频繁查询的复合条件列添加 `@@index([...])`，对多对多或外键关联列建立索引以提升 Agent/Feedback/Trace 等高频表的查询性能。
- PrismaClient 通过 `globalThis` 单例模式创建并缓存，仅在 development 环境下启用 query/error/warn 日志级别。
