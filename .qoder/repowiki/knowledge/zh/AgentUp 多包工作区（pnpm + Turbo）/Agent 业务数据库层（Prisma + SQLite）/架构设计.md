模块以 `prisma/schema.prisma` 为唯一数据源描述，使用 SQLite 作为后端（PostgreSQL 历史迁移已删除），并通过 `@prisma/client` 生成类型。

- 运行时入口：`src/index.ts` 仅 re-export `prisma` 实例、`enums`、`json-text` 以及全部 `@prisma/client` 生成的类型，对外不暴露内部实现。
- 连接管理：`src/client.ts` 通过 `globalThis` 单例持有 `PrismaClient`，在 development 下开启 query/error/warn 日志，production 仅保留 error；非生产环境缓存到全局避免热重载重复创建连接。
- 类型与存储分离：由于 SQLite 连接器不支持 enum/Json/标量数组，所有原 enum 字段改为 `String`，由 `src/enums.ts` 中的 const 对象 + union type 提供类型约束，值域校验下沉到调用方的 Zod schema；所有原 Json/String[] 字段以 `String` 列存储 JSON 文本，读写经 `src/json-text.ts` 的 `packJson`/`unpackJson` 收口，解析失败回落 fallback 且不抛错。
- 脚本与种子：`prisma/seed.mjs`、`prisma/seed-data.mjs`、`prisma/wiki-corpus.mjs` 配合 `scripts/build-wiki-corpus.mjs` 提供初始数据与知识库语料构建；`.env` 提供 `DATABASE_URL`。
- 依赖方向：本包被上层业务模块消费，自身仅依赖 `@prisma/client`，无 HTTP/框架耦合。
