- API 路由统一以 `success(data, status?)` / `error(msg, code?, details?)` 包裹返回体，异常经 `handleApiError` 转换。
- 请求体先经 `parseBody` 再交由 Zod schema（`createFeedbackSchema` / `updateFeedbackSchema` / `feedbackIngestSchema`）`safeParse` 校验，失败返回 422。
- 写操作在业务调用外层包裹 `withActor(resolveActor(request.headers), () => ...)`，将当前用户/系统身份注入服务层。
- 前端对异步副作用统一采用 try/catch + `finally` 清理 loading/moving 状态，并在错误时设置本地 `error`/`moveError` 通过 `<Alert tone="danger">` 展示。
- 枚举型字段（status、severity、rating、targetPartition）一律通过 `metaOf(FEEDBACK_STATUS|SEVERITY|RATING|PARTITION, code)` 取 label/desc/tone，避免硬编码文案。
