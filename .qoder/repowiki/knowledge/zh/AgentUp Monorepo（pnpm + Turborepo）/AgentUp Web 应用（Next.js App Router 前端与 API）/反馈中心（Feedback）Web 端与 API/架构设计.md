模块按 Next.js App Router 约定分为两层：
- 客户端页面 `apps/web/app/(dashboard)/feedback/page.tsx`：使用 `'use client'` 的 React 组件，通过 `fetch` 直接调用 `/api/feedback` 系列端点；内置状态机 `NEXT_STATUS` 控制「待分诊→已分诊→已指派→处理中→已解决→已验证→已关闭」及「不予处理」流转，并提供「AI 归因」按钮触发 `/api/feedback/[id]/insight`。
- API 路由 `apps/web/app/api/feedback/`：遵循 REST 风格——`route.ts` 暴露 GET(列表)、POST(创建)、PUT(更新)，`[id]/insight/route.ts` 暴露 POST(LLM 归因)，`ingest/route.ts` 暴露机器接入专用 POST。所有路由统一通过 `@/lib/utils` 的 `success/error/handleApiError` 包装响应，并通过 `withActor(resolveActor(...))` 注入当前 Actor 上下文后委派给 `@/lib/services/feedback-service` 的业务层。
依赖方向单向向外：页面 → API 路由 → services → db/llm；本模块不直接访问数据库或 LLM，仅作为 UI 与编排层。
