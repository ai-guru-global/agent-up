本模块由两部分组成：`apps/web/app/(dashboard)/wiki/page.tsx` 是客户端页面，作为用户操作入口；`apps/web/app/api/wiki/` 是服务端 REST 路由，按资源划分为 `vaults/`（Vault CRUD、分页列表）与 `pages/[id]/route.ts`（单页操作），并额外提供 `vaults/[id]/search` 全文检索端点。页面通过 `fetch` 直接调用 `/api/wiki/vaults`、`/api/wiki/vaults/:id/pages`、`/api/wiki/vaults/:id/search` 等路径，以 `{ success, data | error }` 统一响应结构进行交互，从而把 UI 状态（选中 Vault、页面列表、检索结果）与后端数据源解耦。
