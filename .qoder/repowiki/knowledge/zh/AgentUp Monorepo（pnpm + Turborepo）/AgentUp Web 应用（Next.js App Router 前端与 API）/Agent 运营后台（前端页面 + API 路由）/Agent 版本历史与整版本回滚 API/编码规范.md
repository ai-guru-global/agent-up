- API 路由统一使用 `try/catch` 捕获异常并通过 `handleApiError` 返回，成功路径用 `success(...)` 包装响应体。
- 涉及副作用（效能报告计算、回滚）的操作必须包裹在 `withActor(resolveActor(request.headers), ...)` 中以携带审计 actor 上下文。
- 参数解析采用 Next.js 14 的 `params: Promise<{...}>` 异步形式，先 `await params` 再取字段。
- 对外暴露的 DTO 统一通过 `toVersionResponse` 从 Prisma 实体转换，避免直接透传数据库模型。
