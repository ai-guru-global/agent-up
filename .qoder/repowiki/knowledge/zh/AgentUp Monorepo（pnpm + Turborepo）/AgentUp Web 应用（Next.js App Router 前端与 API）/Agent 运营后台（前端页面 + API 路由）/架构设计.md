本模块按 Next.js App Router 的目录约定将 UI 与 API 解耦：
- `apps/web/app/(dashboard)/agents/` 提供客户端页面（列表、详情、四分区配置编辑、评测用例、证据链），通过调用同名的 `app/api/agents/` 下 RESTful 路由完成数据交互。
- `app/api/agents/route.ts` 作为顶层入口，子路由按资源划分：`[id]/versions` 与 `release/rollback` 负责版本快照与整版本回滚；`[id]/config/[partition]` 负责 prompt/knowledge/tools/routing 四个分区的读写与回滚；`skills`、`eval-cases`、`evidence-chain`、`chat`、`version-lineage` 分别对应技能绑定、评测用例、证据链、在线试聊与版本谱系查询。
- 前端详情页 `[id]/page.tsx` 与后端 `[id]/route.ts` 一一对应，形成「页面 → 同名 API 路由」的直连契约，跨子模块的能力（如版本回滚、分区配置、评测用例）由同一 `/api/agents/[id]/...` 命名空间对外暴露，避免跨域或额外网关。
