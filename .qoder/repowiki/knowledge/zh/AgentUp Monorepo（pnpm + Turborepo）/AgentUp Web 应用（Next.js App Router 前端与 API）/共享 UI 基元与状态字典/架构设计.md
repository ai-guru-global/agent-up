模块以 `index.ts` 作为单一入口，统一 re-export `status`、`primitives`、`form`、`modal` 四个子文件；调用方通过 `@/components/ui` 导入，避免在页面中各自实现同类样式。

- `status.ts`：纯数据层，定义 `Tone` 类型与 `StatusMeta` 接口，集中维护 Agent/Feedback/Skill/Release/Wiki 等生命周期枚举及其中文 label、tone、desc，并提供 `metaOf`、`tagHelp` 等安全降级查找函数，被 primitives 依赖。
- `primitives.tsx`：无业务语义的展示型基元（Button、IconButton、Badge、Card、PageHeader、Alert、EmptyState、Skeleton、LoadingBlock、SectionTitle、MockTag、KeyValue、Spinner），所有颜色通过 CSS 变量 `--accent/--surface/--border` 等语义 token 引用，不出现硬编码色值；内部用轻量 `cn` 合并 className。
- `form.tsx`：基于 React `useId` 建立 label↔控件 id 关联，提供 Field/InlineField/Input/Select/Textarea/FormActions，错误提示使用 `role="alert"`，支持 `hideLabel` 用于工具栏内隐藏标签但保留读屏可读性。
- `modal.tsx`：基于 `Modal` 实现带焦点陷阱、ESC 关闭、滚动锁定的无障碍对话框，并派生 `ConfirmDialog` 替代原生 `confirm()`；依赖 primitives 中的 Button/Alert/cn。

依赖方向单向：`modal` → `primitives` → `status`，`form` 仅依赖 `primitives` 的 `cn`，不存在反向引用。
