- 所有颜色与背景通过 CSS 变量（如 `var(--accent)`、`var(--surface-elevated)`、`var(--border)`）引用，禁止在组件内写死十六进制色值。
- className 拼接统一走模块内导出的 `cn` 辅助函数，过滤 false/null/undefined 后 join 空格。
- 可交互元素（Button、IconButton、Modal 关闭按钮等）同时设置 `aria-label` / `title` / `focus-visible:outline-*`，确保键盘与读屏可用。
- 状态类 UI 通过 `status.ts` 中的字典 + `metaOf` 取 label/tone/desc，未登记的值安全降级显示原始 code，避免硬编码分支。
- 组件 Props 先声明独立 interface（如 `ButtonProps`、`ModalProps`、`FieldProps`），再在函数签名中解构默认值。
- 每个文件顶部以注释说明“建立此文件前”的重复问题，明确该文件的收敛目标与无障碍/可访问性约束。
