模块由两部分组成：
- 客户端页面 `apps/web/app/(dashboard)/skills/page.tsx`：一个 `use client` 组件，使用内部 UI 组件库（`@/components/ui`）渲染 Skill 卡片网格，并通过 `fetch('/api/skills')` 调用后端接口；内置分类（KNOWLEDGE_QUERY/DATA_FETCH/ACTION/TRANSFORM/GENERAL）、状态（DRAFT/PUBLISHED/DEPRECATED/ARCHIVED）与运行时（HTTP/FUNCTION/MCP/WORKFLOW）等枚举常量，以及一个内嵌的 `CreateSkillModal` 子组件负责 POST 创建。
- API 路由 `apps/web/app/api/skills/route.ts` 与 `[id]/route.ts`：基于 Next.js App Router 的 Route Handlers，分别暴露 GET/POST 列表与创建、GET/PUT/DELETE 单条资源；所有写操作通过 `withActor(resolveActor(request.headers), ...)` 注入当前 Actor 上下文后委托给 `@/lib/services/skill-service` 中的领域服务函数，请求体校验统一走 `validateBody` + Zod schema（`createSkillSchema` / `updateSkillSchema`），响应统一用 `success` / `error` 包装并经由 `handleApiError` 转换异常。
依赖方向单向向外：页面 → `/api/skills` → service layer → 数据库，本模块不直接访问数据库或 ORM。
