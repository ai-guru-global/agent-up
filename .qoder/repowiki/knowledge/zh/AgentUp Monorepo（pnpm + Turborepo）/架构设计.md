根目录作为 monorepo 入口，通过 pnpm-workspace.yaml 将 web_app、db_package、chrome_extension、docs、knowledge_base 纳入同一依赖图；turbo.json 定义跨包 task 依赖链：build 先触发 ^build 与 ^db:generate，dev 强制依赖 db:generate，lint 依赖 build，所有 db:* 与 clean 任务关闭缓存以保证 SQLite 状态一致。
- 运行时边界：web_app 是主 Node/Next.js 进程，消费 db_package 的 Prisma 客户端访问 SQLite；chrome_extension 作为独立 MV3 扩展，仅通过 HTTP 调用 web_app 暴露的 /api/feedback 端点上报反馈，二者无共享代码。
- 资产边界：docs 与 knowledge_base 为纯 Markdown，不参与编译，由 code-up.yaml / skills-up.yaml 驱动的 AI 蒸馏与 gate.py 技能门禁流程消费。
- 类型与引擎：tsconfig.json 提供全局 TS 编译基线（ES2022、bundler 解析、strict + noEmit），Node ≥20 为运行约束。
