该模块是一个纯函数优先的服务层，核心由两个导出函数组成：`computeEffectivenessReport` 是纯计算函数，仅依赖输入参数完成窗口内 feedback 的过滤与三类维度聚合；`getOrComputeEffectivenessReport` 负责 I/O 编排——从 `@/lib/data/store` 读取磁盘上的 version 与 feedback，判断是否进入效果窗口，调用纯函数计算后将结果写回并触发审计记录。设计采用「懒填」模式：不在后台定时任务中预计算，而是在 GET version 时按需触发，避免运维成本。并发安全通过 store 的全量覆盖语义保证幂等。模块仅依赖 `store` 和 `audit-service`，不反向依赖上层 API 或 UI。
