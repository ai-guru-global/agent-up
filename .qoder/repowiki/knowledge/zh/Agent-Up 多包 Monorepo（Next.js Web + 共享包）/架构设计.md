根目录通过 pnpm-workspace.yaml 聚合 apps/* 与 packages/*，由 turbo.json 定义跨包的 build/dev/lint/db:* 任务依赖图：所有子包在构建前必须先执行 ^db:generate，Web 应用的 .next 与 dist 作为输出缓存。apps/web 是唯一的运行时入口，提供 App Router 页面与 API Routes；packages/db、packages/shared、packages/ui 为被多个子包复用的共享层。各子模块之间通过 Node 模块解析引用 shared/db/ui，API 层（如 agents/versions 路由）调用 services 层处理业务逻辑，数据层以 JSON 快照或 Prisma 模型持久化，形成「API → Services → Data」的分层结构。
