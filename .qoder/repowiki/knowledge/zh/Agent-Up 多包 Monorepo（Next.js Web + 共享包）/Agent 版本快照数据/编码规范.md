- 每个版本文件以 `ver-{agent-suffix}-{seq}.json` 命名，id 字段与文件名保持一致。
- 所有版本快照保持统一的顶层字段结构（promptSnapshot/knowledgeSnapshot/toolsSnapshot/routingSnapshot/effectivenessReport），仅允许字段值变化而非结构变更。
- 发布时间使用 ISO 8601 UTC 格式（`publishedAt`、`computedAt`），由发布者（`publishedBy`）和变更说明（`changeNote`）共同记录审计轨迹。
- effectivenessReport 始终包含 byRating/bySeverity/byPartition 三个维度的计数初始化为 0，并附带 computedAt 与 windowDays 用于统计窗口控制。
