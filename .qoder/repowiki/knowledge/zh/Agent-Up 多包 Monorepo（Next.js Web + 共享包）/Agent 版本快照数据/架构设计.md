该模块为纯数据目录，每个 `ver-*.json` 文件代表一个不可变的 Agent 版本快照，结构统一包含：元信息（id、agentId、语义化 version/major/minor/patch）、promptSnapshot（systemPrompt、roleDefinition、constraints、outputFormat）、knowledgeSnapshot（wikiVaultId、searchStrategy、fallbackToMcp、maxWikiResults、confidenceThreshold）、toolsSnapshot（mcpTools、wikiQueryTools、并发/超时/重试配置）、routingSnapshot（rules 列表、defaultAction、humanThreshold、会话限制）、发布审计字段（releaseId、publishedBy、publishedAt、changeNote）以及 effectivenessReport（按评分、严重级别、分区维度统计反馈）。不同 Agent 通过 agentId 区分，同一 Agent 的多版本并存（如 ver-001、ver-002），由外部加载器按 id 或版本号检索。
