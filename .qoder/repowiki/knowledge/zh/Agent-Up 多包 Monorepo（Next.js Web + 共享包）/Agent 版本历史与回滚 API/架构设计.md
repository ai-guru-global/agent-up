基于 Next.js App Router 的 Route Handler 组织，四个 route.ts 文件分别对应三个 REST 端点：`GET /api/agents/[id]/versions`（列出某 Agent 的所有 Version 并 lazy 填充 effectivenessReport）、`GET /api/agents/[id]/versions/[versionId]`（单个 Version 详情）、`POST /api/agents/[id]/config/[partition]/rollback`（单分区回滚）和 `POST /api/agents/[id]/rollback/[versionId]`（整版本回滚）。数据层通过 `@/lib/data/store` 读写 versions 集合；业务逻辑委托给 `agent-service`、`release-service`、`effectiveness-service` 等上层服务模块；权限与审计通过 `@/lib/context` 的 `withActor`/`resolveActor` 包裹执行上下文。错误统一抛出 `NotFoundError`/`ValidationError`，响应统一经 `success`/`error`/`handleApiError` 包装。
