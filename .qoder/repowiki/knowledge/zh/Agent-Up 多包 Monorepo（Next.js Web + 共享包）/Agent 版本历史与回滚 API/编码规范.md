- 所有 Route Handler 的 GET/POST 函数接收 `NextRequest` 与 `params: Promise<{...}>` 形式的路由参数，并通过 `await params` 解构。
- 成功响应统一通过 `@/lib/utils` 的 `success()` 包装返回，异常统一走 `handleApiError(err)` 捕获。
- 需要身份上下文的写操作使用 `withActor(resolveActor(request.headers), async () => {...})` 包裹业务逻辑。
- 请求体验证使用 `validateBody(request, zodSchema)` 模式，失败时直接返回 `validated.response`。
- 对 store 读取到的 version 进行归属校验（`version.agentId !== id`），不匹配时抛出 `ValidationError`。
