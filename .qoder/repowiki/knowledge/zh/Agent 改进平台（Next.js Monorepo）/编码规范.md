- Route Handler 统一通过 `resolveActor(headers)` 解析请求头中的 x-actor-id/name/role，并用 `withActor` 包裹 service 调用以注入当前 Actor 上下文。
- 跨包共享的类型集中在 `packages/shared/src/types/*`，并通过 `index.ts` 统一 re-export，避免重复定义。
- API 路由按资源域组织目录（agents/releases/skills/wiki/settings 等），每个子资源再按 `[id]` 动态段拆分单条资源路由。
- 输入校验统一使用 Zod schema（`lib/schemas.ts`），在 Route Handler 入口处对 query/body params 进行解析后再进入 service 层。
- 测试用例与业务代码同目录放置（`__tests__` 或同级 `.test.ts`），并使用 `lib/context.ts` 提供的 `resetActor` 隔离请求级 Actor 状态。
- Turborepo 任务通过 `dependsOn` 声明上游依赖（如 build 依赖 `^build` 和 `^db:generate`），保证包间构建顺序。
