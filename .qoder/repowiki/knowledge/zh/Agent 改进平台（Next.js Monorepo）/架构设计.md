仓库为 pnpm workspace + Turborepo 多包 monorepo：根 `package.json` 通过 `turbo run` 编排 `dev/build/lint/db:*` 任务；`apps/web` 是唯一的 Next.js 16 应用，使用 App Router 按路由分组 `(auth)`/`(dashboard)`，并通过 `app/api/**` 暴露 Route Handler 作为后端接口；`packages/shared` 集中定义跨包共享的类型（agent/feedback/release/skill/wiki/permission）与常量；`packages/db` 封装 Prisma Client（schema 位于 `prisma/schema.prisma`），对外暴露 `client.ts`；`packages/ui` 预留 UI 组件包。依赖方向严格单向：`apps/web` → `@agent-up/shared` + `@agent-up/db`，各 packages 之间无相互引用。运行时上下文通过 `apps/web/lib/context.ts` 的模块级 Actor 栈在 Route Handler 中注入当前调用者，service 层统一通过 `getActor()` 获取，便于未来接入 NextAuth/JWT。业务数据目前以 `apps/web/data/**/*.json` 静态 JSON 文件模拟，配合 `lib/services`、`lib/schemas.ts`（Zod 校验）、`lib/versioning.ts` 实现领域逻辑，测试由 Vitest 覆盖。
