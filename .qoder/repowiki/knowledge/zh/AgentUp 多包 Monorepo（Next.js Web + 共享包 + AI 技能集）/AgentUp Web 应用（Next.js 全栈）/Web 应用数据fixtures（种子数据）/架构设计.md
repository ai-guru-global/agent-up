该模块是一个纯数据目录，按业务域划分子文件夹：agents/存放 Agent 配置（含 promptConfig、knowledgeConfig、toolsConfig、routingConfig），skills/存放可复用的技能定义（HTTP 运行时 + input/output schema），wiki-vaults/以嵌套 pages/ 子目录组织知识库页面，settings/集中管理 roles.json、permissions.json、product-groups.json、audit-logs.json 等系统设置，feedback/和 releases/分别存放反馈与发布记录的示例数据。每个 JSON 文件都遵循统一的 id/name/description/createdAt/updatedAt/_count 元数据约定，并通过 id 字段在文件间建立关联（如 agents 的 productGroupId 指向 settings/product-groups.json，wiki-vaults 的 agentId 指向 agents）。所有数据均为只读 fixtures，不包含任何代码逻辑。
