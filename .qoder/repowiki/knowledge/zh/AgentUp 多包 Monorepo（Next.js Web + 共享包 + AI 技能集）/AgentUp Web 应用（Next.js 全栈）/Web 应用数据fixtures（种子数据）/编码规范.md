- 每个实体文件都包含 id、name、description、status、createdAt、updatedAt、createdBy 等标准元数字段，便于统一序列化与审计。
- 通过 _count 字段维护关联实体的计数（如 feedbacks、releases、versions、bindings、pages 等），用于前端展示统计信息。
- 跨文件关联统一使用 id 引用（如 productGroupId、agentId、wikiVaultId），保持引用关系清晰且可追踪。
- JSON 数组型数据（如 roles.json）将多个同构实体放在单个文件中，对象型数据（如 agents、skills、wiki-vaults）则一文件一实体。
- 枚举值统一使用大写下划线风格（如 ACTIVE、PUBLISHED、WIKI_FIRST、DATA_FETCH、HTTP 等），避免大小写混用。
