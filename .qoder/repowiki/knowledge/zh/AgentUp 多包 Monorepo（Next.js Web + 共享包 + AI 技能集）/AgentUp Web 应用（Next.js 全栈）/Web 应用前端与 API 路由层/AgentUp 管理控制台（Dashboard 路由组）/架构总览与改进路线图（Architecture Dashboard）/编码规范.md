- 每个页面文件导出一个默认 React 函数组件，使用 `export default function XxxPage()` 命名约定，并在组件顶部定义 Mermaid 图表为常量模板字符串。
- 页面结构统一通过 `Section` 组件包裹内容区块，配合 `PageHeader` 提供标题、副标题和 badge，`Insight` 组件用于高亮关键洞察。
- 表格数据以二维数组形式传入 `Table` 组件，表头 `head` 为字符串数组，单元格 `rows` 元素可为 ReactNode（支持 `<strong>`、`<Pill tone="...">`、`<ScoreDots score={N} />` 等复合内容）。
- 跨页面导航通过 `NavGrid` 组件声明式配置 `{ title, description, href, tag? }` 数组，而非硬编码链接，保持导航一致性。
- 引用来源统一使用 `References` 组件，以 `{ title, url, note? }[]` 格式声明，外部链接带 `target="_blank" rel="noopener noreferrer"`。
- 颜色语义通过 Tailwind CSS 变量（`var(--accent)`、`var(--surface)`、`var(--border)`、`var(--surface-elevated)`）而非硬编码色值，确保主题一致性。
