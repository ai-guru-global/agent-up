该模块是 Next.js App Router 下的一个路由组 `(dashboard)/architecture`，采用「入口页 + 子页面」结构：`page.tsx` 作为架构总览入口，聚合项目定位、三层 Loop 全景、四分区配置、八维评分、创意性评估、行业差距、技术债与 Top5 缺口，并通过 `NavGrid` 组件导航到三个子页面——`harness/page.tsx`（Harness 工程）、`loop/page.tsx`（Loop 工程）、`roadmap/page.tsx`（改进路线图）。所有页面共享 `_components/ui.tsx` 中的无状态 UI 原子组件（PageHeader、Section、Card、Table、Pill、ScoreDots、Insight、References、NavGrid），图表统一通过 `../../../components/mermaid` 的 `<Mermaid>` 组件渲染内联 Mermaid 字符串。依赖方向单向：各 page → `_components/ui` → 全局 `Mermaid` 组件，无业务逻辑耦合，纯展示层。
