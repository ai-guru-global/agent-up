该模块以 `layout.tsx` 作为所有子页面的共享外壳：左侧固定 56px 宽导航栏通过 `navItems` 和 `archItems` 两个数组声明式维护路由映射，使用 `usePathname` + `isActive` 实现高亮；内容区由 `ErrorBoundary` 包裹，确保单个页面崩溃不影响整体导航。各业务页（agents、feedback、releases、skills、wiki、settings、architecture/*）均为独立的 Route Segment，遵循 `"use client"` 客户端组件模式，并通过 `/api/dashboard` 等 API 路由获取数据。`page.tsx` 作为控制台首页汇总 Agent/反馈/发布统计，并向下级页面提供跳转入口。
