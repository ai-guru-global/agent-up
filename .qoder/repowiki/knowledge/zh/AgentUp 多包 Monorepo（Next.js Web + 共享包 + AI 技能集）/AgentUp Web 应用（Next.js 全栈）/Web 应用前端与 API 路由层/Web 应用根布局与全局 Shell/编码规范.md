- 客户端组件统一在文件顶部使用 `'use client'` 指令声明。
- 主题色与字体通过 CSS 自定义属性（`--background`、`--foreground`、`--accent`、`--font-geist-sans` 等）集中定义在 `globals.css` 中，并在 Tailwind `@theme inline` 内映射为 `color-*` 与 `font-*` 变量。
- 深色模式通过 `@media (prefers-color-scheme: dark)` 覆盖 `:root` 中的 CSS 变量实现，组件侧通过 `window.matchMedia` 或 CSS 变量读取适配。
- 组件采用函数式组件 + TypeScript 接口（Props/State）定义，错误处理通过 try/catch 或 `getDerivedStateFromError` 捕获并降级展示。
