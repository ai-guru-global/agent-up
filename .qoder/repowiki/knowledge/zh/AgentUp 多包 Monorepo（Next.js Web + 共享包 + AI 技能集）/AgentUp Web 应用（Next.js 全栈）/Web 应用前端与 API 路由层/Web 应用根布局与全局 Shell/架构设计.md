基于 Next.js App Router 的根目录结构：`layout.tsx` 作为 RootLayout 注入 Geist Sans/Mono 字体变量并引入 `globals.css`；`page.tsx` 是默认首页，通过 `next/link` 导航到 `/agents` 和 `/login`；`global-error.tsx` 使用 `'use client'` 定义全局错误兜底页面；`components/error-boundary.tsx` 是基于 class Component 的 React 错误边界，用于捕获子树渲染异常；`components/mermaid.tsx` 是客户端 Mermaid 渲染封装，动态读取 CSS 变量生成与主题一致的图表样式。依赖方向单向向下：layout → globals.css → Tailwind @theme 变量；组件仅依赖 React 与 mermaid 库，不反向引用 layout。
