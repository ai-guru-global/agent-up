- 每个资源目录仅暴露 `GET`/`POST`（及可选的 `PUT`/`DELETE`）异步函数，遵循 Next.js App Router 的 HTTP 方法导出约定。
- 写操作统一通过 `withActor(resolveActor(request.headers), () => { ... })` 包裹，确保审计日志能关联到当前操作用户。
- 请求体校验使用 `validateBody(request, createXxxSchema)` 模式，失败时直接返回 `validated.response`，成功时从 `validated.data` 读取字段。
- 所有响应通过 `success(data, statusCode?)` 包装返回，错误通过 `handleApiError(err)` 统一处理并转换为标准格式。
- CRUD 操作在修改数据后调用 `recordAudit(action, resourceType, resourceId, payload)` 记录审计日志，action 命名采用 `resource.verb` 形式。
- 新增资源统一生成 `id: store.generateId()`，并初始化 `_count` 计数字段（如 `{ roles: 0 }`、`{ agents: 0, members: 0 }`、`{ members: 0 }`）。
