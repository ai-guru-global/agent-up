该模块采用 Next.js App Router 的文件路由约定，每个资源目录对应一个 `route.ts` 文件：`audit-logs/`、`permissions/`、`product-groups/` 为单端点资源（仅 GET/POST），`roles/` 通过嵌套 `[id]/route.ts` 支持 PUT/DELETE 单个资源操作。所有路由统一依赖三层基础设施：`@/lib/data/store` 作为 JSON 文件存储层（`readArray`/`writeArray`/`generateId`/`now`），`@/lib/utils` 提供 `success`/`validateBody`/`handleApiError`/`parsePagination` 等通用响应与校验工具，`@/lib/schemas` 提供 Zod 校验模式，`@/lib/services/audit-service` 记录审计日志，`@/lib/context` 的 `withActor(resolveActor(...))` 包裹写操作以注入当前操作用户上下文。数据持久化全部落盘到 `settings/*.json` 文件，无外部数据库依赖。
