采用 Next.js App Router 的动态路由结构：根 `route.ts` 暴露 `/api/agents`（GET 列表 + POST 创建）；`[id]/route.ts` 处理单个 Agent 的 GET/PUT/DELETE；`[id]/config/[partition]/route.ts` 按 prompt/knowledge/tools/routing 四个分区管理配置；`[id]/skills/route.ts` 管理技能绑定。每个路由文件仅做请求解析、参数校验与错误包装，业务逻辑委托给 `@/lib/services/*` 层（agent-service、skill-service），上下文通过 `withActor(resolveActor(...))` 注入当前操作者。响应统一通过 `@/lib/utils` 的 `success/error/handleApiError` 封装，入参通过 `validateBody` + zod schema 校验。
