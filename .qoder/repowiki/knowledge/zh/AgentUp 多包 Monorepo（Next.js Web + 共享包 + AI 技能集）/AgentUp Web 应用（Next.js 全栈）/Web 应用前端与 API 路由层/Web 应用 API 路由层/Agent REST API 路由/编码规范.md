- 所有写操作（POST/PUT/DELETE）通过 `withActor(resolveActor(request.headers), ...)` 包裹服务调用以注入当前操作者上下文。
- 请求体统一使用 `validateBody(request, schema)` 进行 zod 校验，失败时直接返回 `validated.response`。
- 响应一律通过 `@/lib/utils` 的 `success(data, status?)` / `error(message, status)` 封装，异常由 `handleApiError(err)` 统一转换。
- 动态路由参数通过 `{ params }: { params: Promise<{ id: string }> }` 解构并 `await params` 获取。
- 分区类路由使用 `VALID_PARTITIONS` 常量配合类型守卫函数 `isValidPartition` 进行白名单校验后再进入分支处理。
