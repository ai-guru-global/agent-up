测试文件按被测路由目录结构一一对应：`agents.test.ts` 对应 `@/app/api/agents/*`，`feedback-skills-wiki.test.ts` 对应 `@/app/api/feedback`、`skills`、`wiki/vaults`，`releases.test.ts` 对应 `@/app/api/releases/*` 及 `agents/[id]/release`。每个测试文件直接 import 被测 route 的 GET/POST/PUT/DELETE 导出函数，通过构造 `NextRequest` 并传入 `{ params: Promise.resolve({...}) }` 模拟 Next.js App Router 的路由参数，不启动 HTTP 服务器，属于纯函数式集成测试。数据持久化通过共享的 `@/lib/data/store` 配合 `useTempDataDir` / `restoreDataDir` 在 `beforeEach`/`afterEach` 中切换临时数据目录，确保用例间隔离。
