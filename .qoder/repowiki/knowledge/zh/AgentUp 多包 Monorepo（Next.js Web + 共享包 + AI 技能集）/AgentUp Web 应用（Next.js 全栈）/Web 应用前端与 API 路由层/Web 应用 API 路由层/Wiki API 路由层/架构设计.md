该模块采用 Next.js App Router 的文件路由约定，每个 `route.ts` 文件对应一个 HTTP 端点，按资源层次组织：根级 `/wiki/pages/[id]` 管理单个页面，`/wiki/vaults` 管理知识库（Vault），`/wiki/vaults/[id]/pages` 管理某 Vault 下的页面集合。

每类路由遵循统一分层：HTTP 参数解析 → 请求体验证（`validateBody` + Zod schema）→ 身份上下文注入（`withActor(resolveActor(...))`）→ 调用领域服务（`@/lib/services/wiki-service`）→ 统一响应包装（`success`/`error`）→ 异常捕获（`handleApiError`）。路由层仅做编排，不持有业务逻辑，依赖方向单向指向 `@/lib/utils`、`@/lib/schemas`、`@/lib/services/wiki-service` 和 `@/lib/context`。
