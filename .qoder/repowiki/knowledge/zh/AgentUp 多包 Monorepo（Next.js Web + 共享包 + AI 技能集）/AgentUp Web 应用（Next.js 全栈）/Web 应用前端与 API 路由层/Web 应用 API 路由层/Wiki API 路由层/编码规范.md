- 每个 route.ts 导出 GET/POST/PUT/DELETE 异步函数，通过 `params` 为 Promise 的形式解构动态路由参数（如 `{ id } = await params`）。
- 写操作统一使用 `validateBody(request, <schema>)` 进行请求体验证，失败时直接返回 `validated.response`。
- 涉及权限的操作通过 `withActor(resolveActor(request.headers), () => ...)` 包裹业务调用，将当前 Actor 注入到服务层。
- 成功响应一律用 `success(data, status?)` 包装，404 等错误用 `error(message, status)` 返回，异常统一由 `handleApiError(err)` 处理。
- 列表接口通过 `parsePagination(searchParams)` 解析分页参数，并用 `paginationMeta(page, pageSize, total)` 生成分页元数据。
