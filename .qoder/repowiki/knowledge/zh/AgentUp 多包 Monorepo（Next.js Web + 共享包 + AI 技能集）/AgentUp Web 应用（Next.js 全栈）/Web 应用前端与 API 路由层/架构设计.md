本模块以 Next.js App Router 为统一框架，将页面与 API 路由按目录结构一一对应：`app/(auth)/login` 处理认证流程，`app/(dashboard)` 通过 `layout.tsx` 注入侧边栏布局聚合所有管理页面，`app/api/*` 按 agents、settings、wiki、releases、feedback、skills 等域组织 REST 端点，每个页面路由通常对应同名的 API 路由（如 `agents/[id]/route.ts` 与 `agents/[id]/page.tsx`）。根级 `layout.tsx`、`global-error.tsx`、`globals.css`、`components/` 提供跨页面的字体注入、主题变量、Mermaid 渲染和错误边界能力，使页面组与 API 路由共享同一运行时环境。
