本模块以 Next.js App Router 为统一入口：`app/` 下的 `(auth)` 和 `(dashboard)` 路由组分别承载登录与管理控制台页面，`app/api/` 按功能域（agents、releases、skills、wiki、settings、feedback、auth）暴露 RESTful 接口；所有业务逻辑通过 `lib/` 中的核心库（context.ts、schemas.ts、errors.ts、services/*、data/*）实现，数据层由 `data/` 下的静态 JSON fixtures 提供持久化模拟。API 路由与页面组件共同消费同一套 Zod schema 与服务函数，形成「页面 → API 路由 → lib/services → lib/data(JSON文件)」的单向依赖链，确保前后端共享一致的输入校验与错误模型。
