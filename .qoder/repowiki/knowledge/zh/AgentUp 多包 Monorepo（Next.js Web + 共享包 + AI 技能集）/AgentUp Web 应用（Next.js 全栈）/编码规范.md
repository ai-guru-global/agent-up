- API 路由采用 Next.js App Router 的文件路由约定，按功能域在 `app/api/<domain>/route.ts` 中组织，动态参数使用 `[id]` 目录命名。
- 输入校验统一通过 `lib/schemas.ts` 中的 Zod schema 定义，API 路由与页面组件复用同一份 schema。
- 错误处理遵循 `lib/errors.ts` 定义的统一错误类型，API 路由返回标准化错误响应结构。
- 数据访问通过 `lib/services/*` 封装领域服务，再由 `lib/data/*` 基于 JSON 文件进行读写，避免直接操作文件系统。
- 测试用例集中放在 `__tests__/` 目录下，使用 Vitest 框架对 API 路由和服务函数进行断言。
