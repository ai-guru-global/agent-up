根目录通过 `pnpm-workspace.yaml` 声明 `apps/*` 与 `packages/*` 两个工作区，由 `turbo.json` 统一调度各子包的 build/dev/lint/db:* 任务，并依赖 `.env` 作为全局变量注入。`apps/web` 是唯一的用户入口（Next.js App Router），通过 `packages/shared`、`packages/db`、`packages/ui` 提供类型、数据模型与 UI 组件；`.agents/skills` 以 Markdown SKILL.md 形式为 Agent 注入品牌、视觉、图像生成等专项能力；`.zcode/plans` 存放 P0 质量加固实施计划。所有子包共享同一 TypeScript 配置与 Node ≥20 运行时约束，数据库相关命令通过 `turbo run db:*` 在 monorepo 内统一触发。
