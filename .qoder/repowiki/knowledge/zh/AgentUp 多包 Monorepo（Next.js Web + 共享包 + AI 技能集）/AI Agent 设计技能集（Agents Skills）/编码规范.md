- 每个技能目录仅包含一个 `SKILL.md`（可选附带 `DESIGN.md`），并通过 YAML front matter 的 `name` 和 `description` 字段进行元数据声明。
- 技能内容采用分节 Markdown 结构，先定义目标与原则，再列出具体规则、反模式（Anti-Patterns/Banned）和输出模板。
- 所有禁止项统一以「BANNED」「NEVER DO」「Avoid」等显式否定词标注，形成可被 LLM 直接解析的强约束清单。
- 涉及数值的地方一律给出精确值（hex 色号、rem/px 尺寸、clamp() 表达式、spring 物理参数等），避免模糊描述。
