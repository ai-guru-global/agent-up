本仓库未发现统一的日志系统。代码中未引入任何第三方日志库（如 pino、winston、bunyan、debug 等），也未定义自定义 logger 模块或结构化日志规范。

唯一与日志相关的实践位于 `packages/db/src/client.ts`：通过 Prisma Client 的 `log` 选项，在开发环境输出 query/error/warn，在生产环境仅输出 error，用于调试数据库查询。其余业务代码（Next.js API route、页面组件）均未使用任何日志输出，API 路由直接返回 JSON 响应而无请求/响应日志记录。

因此该仓库当前不具备可复用的日志体系，后续如需完善，建议引入结构化日志库并在共享包中提供统一 logger 实例。
