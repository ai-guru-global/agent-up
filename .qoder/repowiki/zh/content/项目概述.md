## 简介
Agent Up 是一个面向 AI Agent 的持续改进管理平台，围绕“三层 Loop”理念构建，提供从配置、发布到反馈闭环的全生命周期管理能力。平台通过四分区配置系统（提示词、知识库、工具/MCP、路由）将复杂配置解耦，结合版本控制与审批流程，确保变更可追溯、可回滚；同时以反馈驱动改进，形成“采集—分析—修复—验证”的持续优化循环。

核心价值主张
- 全生命周期管理：从草稿、发布、版本快照到回滚，覆盖 Agent 完整演进路径。
- 四分区配置：将提示词、知识检索、工具调用与路由策略分而治之，降低耦合、提升可维护性。
- 版本与审批：基于 Release 与 AgentVersion 的快照机制，支持审计与回滚。
- 反馈驱动：结构化反馈模型与标签体系，支撑问题定位与效果度量。
- Monorepo 工程化：Next.js + TypeScript + Prisma，配合 Turborepo 与 pnpm workspace，统一脚本与缓存加速。

## 项目结构
仓库采用 Monorepo 组织方式，应用与共享包分离，便于复用类型与 UI 组件。

- 顶层工作区
  - apps/web：Next.js 前端与 API 路由，包含页面、布局、API 入口与数据库客户端封装。
  - packages/shared：跨包共享的类型定义（如 Skill、Feedback）。
  - packages/db、packages/ui：预留的数据库与 UI 包（当前未展开）。
- 关键配置文件
  - turbo.json：Turborepo 任务编排与缓存策略。
  - pnpm-workspace.yaml：工作区包发现规则。
  - docker-compose.yml：本地开发依赖（PostgreSQL、MinIO）。

### 反馈驱动改进闭环
反馈模型支持多来源、多维标签与严重等级，并与目标分区关联，便于定位问题域并驱动配置迭代。

```mermaid
flowchart TD
Start(["开始"]) --> Collect["采集反馈<br/>手动/API/会话导入/系统"]
Collect --> Tag["打标签与定级<br/>答案质量/知识缺口/工具失败/路由错误等"]
Tag --> Triage{"是否影响生产？"}
Triage --> |是| Assign["指派处理人<br/>进入处理队列"]
Triage --> |否| Backlog["纳入待办池"]
Assign --> Fix["修复配置或逻辑<br/>更新对应分区"]
Fix --> Review["评审与测试"]
Review --> Publish["提交发布<br/>生成 Release 与 Version 快照"]
Publish --> Verify["验证与回归"]
Verify --> Close["关闭或继续跟踪"]
Backlog --> Fix
```

## 性能考虑
- 构建与开发缓存：通过 Turborepo 的任务缓存减少重复构建与 lint 时间。
- 数据库连接复用：Prisma Client 全局单例避免热重载下重复创建连接。
- 查询优化：Schema 中对常用字段建立索引（如 Agent.status、Feedback.severity/status、ConfigChange.agentId/partition），有助于列表与筛选性能。
- 并发与超时：ToolsConfig 中的最大并发、超时与重试参数可用于控制外部工具调用的资源占用与稳定性。
- 静态资源与字体：Next.js 内置字体优化可减少首屏阻塞。

## 故障排查指南
- 数据库连接失败
  - 检查环境变量 DATABASE_URL 是否正确指向 PostgreSQL。
  - 确认 docker-compose 已启动且健康检查通过。
- Prisma 客户端未生成
  - 运行 db:generate 确保类型与客户端已生成。
- 端口冲突
  - 默认 PostgreSQL 5432、MinIO 9000/9001，避免与本机服务冲突。
- 构建缓存异常
  - 清理 .turbo 与 .next 目录后重新构建。

## 附录：快速开始
- 环境要求
  - Node.js >= 20
  - pnpm 9.x
  - Docker（可选，用于本地数据库与对象存储）
- 安装步骤
  - 克隆仓库并安装依赖
    - pnpm install
  - 启动本地依赖（可选）
    - docker compose up -d
  - 初始化数据库
    - pnpm run db:generate
    - pnpm run db:push 或 pnpm run db:migrate
  - 启动开发服务器
    - pnpm run dev
  - 打开浏览器访问 http://localhost:3000
- 基本使用示例
  - 进入“我的 Agent”，创建第一个 Agent。
  - 在“配置中心”编辑四分区配置（提示词、知识库、工具/MCP、路由）。
  - 提交发布，查看版本历史与回滚。
  - 在“反馈中心”录入反馈，关联目标分区，推动改进。
